# data-engineering-pipeline
## Versionnement Sémantique

Ce projet suit le versionnement sémantique [SemVer](https://semver.org/lang/fr/), un standard qui permet de comprendre l’impact d’une nouvelle version :

- `MAJOR`: changements incompatibles avec les versions précédentes.
- `MINOR`: ajouts de fonctionnalités rétro-compatibles.
- `PATCH`: corrections de bugs rétro-compatibles.

Exemple : `v1.4.2`
